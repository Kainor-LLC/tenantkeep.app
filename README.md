# tenantkeep.app

The TenantKeep product site: static pages in `docs/`, served by Cloudflare Pages (build output directory `docs`, no build step) like kainor.com. GitHub Pages is not used: it does not allow purchase links. Same
design tokens and fonts as kainor.com (`docs/assets/site.css`).

- `docs/index.html`, `docs/on-call/`, `docs/posture/`: the home page and each product's overview, rendered by `render-site.py` from the hand-written pages in `pages/`. Posture's pricing and its Stripe payment links are in `pages/posture.html`.
- `docs/on-call/how-it-works/`, `docs/on-call/pricing/`, `docs/on-call/glossary/`: rendered by `render-site.py` from the On-Call repository's `docs/` (checked out beside this one as `LAPSlock-repo`)
- `docs/on-call/guide/`, `docs/on-call/architecture/`: rendered by `render-site.py` from `pages/on-call-guide.html` and `pages/on-call-architecture.html`. The guide's pictures are in `docs/assets/on-call/`, made from the app's demo data by the On-Call repository's `scripts/store-screenshots.sh`; never a real tenant's screen.
- `docs/consent/`: where Microsoft returns an administrator after an approval, for both products, with On-Call's apps to approve. Rendered by `render-site.py` from `templates/oncall-app-registrations.json`, a copy of On-Call's published list.
- `docs/guide/`, `docs/licensing/`, `docs/how-it-works/`: rendered from the posture repository's docs
- `docs/catalog/`: the public check catalog, generated by the posture repository's `./build.ps1 -Task Catalog`

Refresh the generated pages after a posture release with `./update-pages.ps1` (needs the posture repository checked out
beside this one).

`site_shell.py` holds the head, navigation and footer every page shares. After changing a template, a page in `pages/`, or On-Call's docs, run `python3 render-site.py`; it needs no posture repository.
