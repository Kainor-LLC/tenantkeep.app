# tenantkeep.com

The Tenantkeep product site: static pages served by GitHub Pages from `docs/`, behind Cloudflare like kainor.com. Same
design tokens and fonts as kainor.com (`docs/assets/site.css`).

- `docs/index.html`: products, principles, pricing (the Stripe payment links), contact
- `docs/guide/`, `docs/licensing/`, `docs/how-it-works/`: rendered from the posture repository's docs
- `docs/catalog/`: the public check catalog, generated by the posture repository's `./build.ps1 -Task Catalog`

Refresh the generated pages after a posture release with `./update-pages.ps1` (needs the posture repository checked out
beside this one).
