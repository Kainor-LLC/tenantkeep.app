How we build

Rules of the garage

Read-only, always

No cmdlet in the module writes to a tenant. The only tenant writes in the repository are the one-time setup scripts your own admin runs: an app registration, a consent, a role grant.

Nothing leaves your environment

No telemetry, no callbacks, no licence server. The licence is a signed file verified offline against public keys built into the module. Evidence and reports stay in your folder or your storage account.

Your identities, your Azure

Local runs use the signed-in admin. The scheduled cycle runs in an Automation account in your subscription with a managed identity and read-only roles you grant and can revoke.

Read it before you trust it

The source is published. Every check is data you can read, every release is signed, and the report says which build produced it.
