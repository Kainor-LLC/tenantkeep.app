Tenantkeep Posture

Consent

One consent per tenant, by an administrator, to a read-only application with no credentials. This page shows the result and nothing more.

If you came here from an admin consent prompt, the result is below. Nothing else happens on this page: no cookie, no script talks to anyone, the address bar is the only input.

Reading the result from the address bar.

What you consented to

Tenantkeep Posture is a multi-tenant application published by Kainor LLC with delegated, read-only permissions and no credentials of its own. Every token it ever holds belongs to the administrator who signed in and goes no further than that administrator's roles. The full list of permissions is in the module's app.json and was on the consent screen. Remove the consent at any time by deleting the enterprise application in Entra ID; the next run says consent is needed.
